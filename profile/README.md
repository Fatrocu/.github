# Fatrocu Organization

The Fatrocu organization maintains the open‑source Fatrocu suite for local invoice processing. The suite includes a desktop GUI, a CLI tool, and an HTTP server, all powered by the Moondream 3.1‑9B‑A2B model.

## Repositories

- **Fatrocu** – Core repository containing the desktop application and shared resources.
- **fatrocu-cli** – Command‑line interface for automation.
- **fatrocu-server** – Lightweight HTTP server exposing a  endpoint.
- **.github** – Organization-wide GitHub configuration and documentation.
